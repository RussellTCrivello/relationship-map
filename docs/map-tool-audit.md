# تدقيق تفاعلات أدوات الخريطة

## ما عولج
- اختيار الموقع والقياس ورسم المنطقة وتعديل شكلها أوضاع متعارضة: تبقى المسودة الحالية ولا تبدأ أداة أخرى قبل إنهائها أو إلغائها. لا يُسمح بالانتقال إلى عرض الشبكة وحده أثناء أداة تحتاج الخريطة.
- تحفظ حقول محرري المواقع والأحداث عند تعذر بدء اختيار موقع. يُظهر الرسم الجاري حتى إن كانت طبقة المناطق مخفية، وتظهر رسالة إذا حُفظت منطقة في طبقة أو تصفية مخفية.
- لا تفتح قوائم الطبقات والتصفية وأشكال المناطق فوق بعضها؛ Escape يغلق القائمة أولاً. عند ضيق العرض تُخفى تعليمات الأداة والشريط الزمني مؤقتاً أثناء فتح القائمة وتعود عند إغلاقها، دون إلغاء العمل.
- تتحقق أداة تعديل الشكل وإعادة الرسم من أن المنطقة الأصلية لم تتغير أثناء التحرير قبل استبدالها. تتوفر أدوات الرسم واختيار الموقع والقياس وتعديل نقاط المنطقة بلوحة المفاتيح؛ تظهر التعليمات أثناء العمل.

## حدود معروفة لم تُنفذ في هذا التعديل
- استيراد وتصدير GeoJSON وKML يدعمان النقاط والمضلعات البسيطة، وليس الخطوط أو المضلعات ذات الفجوات أو الأشكال المتعددة. تُعرض تحذيرات للعناصر غير المدعومة. تُصدَّر الأحداث الشخصية كنقاط ولا تُستعاد علاقتها الأصلية بالكيان؛ لا تستخدم الصيغتين كنسخة احتياطية كاملة للشبكة.
- المناطق المخزنة في إصدار سطح المكتب القديم على منفذ بديل (47832–47851) لا تُنقل تلقائياً إلى مصدر التخزين الثابت 47831؛ راجع `desktop/README.md` قبل ترقية إصدار قديم استخدم منفذاً بديلاً.
- المناطق المحفوظة محلياً تعمل دون اتصال بعد تجهيزها. تنزيل منطقة جديدة والبحث الاختياري عبر الإنترنت يحتاجان اتصالاً؛ لم يُثبت هنا التشغيل الأول الكامل لسطح المكتب دون اتصال.
- لم يُختبر أمر إعداد Windows على Windows في هذا التدقيق. الفحوص أدناه لا تمثل ضماناً لخلو جميع الأجهزة والمتصفحات أو قارئات الشاشة من الأخطاء.

## الفحص
- `TEST_DB_ENGINE=file npm test`
- `npm run test:e2e:map-tools`، ويتطلب Playwright ومتصفح Chromium مثبتين في بيئة الاختبار. يمكن تثبيتهما مؤقتاً باستخدام `npm install --no-save playwright@1.49.1` ثم `npx playwright install chromium`، مع تثبيت متطلبات النظام إذا لزمت.
- يغطي اختبار الأدوات تعارض الأوضاع والمحافظة على المسودات وEscape ومظهر القوائم والجدول الزمني في أحجام 1440 و1100 و700 و390 بكسل، والعمل بلوحة المفاتيح، وحماية التعديل عند تغير المنطقة. صور التحقق في `docs/screenshots/map-tool-audit/`.
